# Скриншоты

Сюда — картинки для README: рабочий стол в каждой теме, бар с открытым
всплывающим окном, приложение настроек, экран входа.

Снять из сессии:

```bash
# всё окружение целиком
flameshot full -p docs/screenshots/desktop-carbon.png

# отдельное окно (кликнуть по нему после запуска)
flameshot gui -p docs/screenshots/settings.png
```

Обои тем лежат в `vxwm/rice/themes/<тема>/wallpaper.png`.
