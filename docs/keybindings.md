# Сочетания клавиш

`Mod` — **Alt** (`Mod1Mask` в `vxwm-src/config.def.h`). Хочешь Super — поменяй
там одну строку `#define MODKEY` и пересобери: `./install.sh --existing --no-packages`.

> **Раскладка переключается по Alt+Shift** (`[input]` в `rice.toml`). Поскольку
> `Mod` — это Alt, любое сочетание из колонки `Mod + Shift + …` ниже заодно
> щёлкнет раскладку. Мешает — смени переключатель на `grp:caps_toggle`
> (CapsLock) или `grp:win_space_toggle` (Super+Пробел), либо переведи `Mod`
> на Super.

Всё, что ниже, живёт в `vxwm-src/config.def.h`: это единственный файл, где
описаны хоткеи. При первой сборке из него делается `config.h` — правь его,
твои правки установщик не затирает.

## Запуск

| Клавиши | Действие |
|---|---|
| `Mod` + `Return` | терминал (kitty) |
| `Mod` + `P` | меню приложений (rofi drun) |
| `Mod` + `B` | браузер (firefox) |
| `Mod` + `E` | файловый менеджер (thunar) |
| `Mod` + `A` | локальный ИИ: плавающее окно kitty с `ollama run llama3` |
| `Mod` + `Escape` | выпадающий терминал (прячется тем же хоткеем) |
| `Print` | скриншот (flameshot) |

## Рис и уведомления

| Клавиши | Действие |
|---|---|
| `Mod` + `W` | выбор темы (меню на rofi) |
| `Mod` + `Shift` + `W` | настройки риса — цвета, бар, композитор, сессия |
| `Mod` + `` ` `` | спрятать/вернуть бар |
| `Mod` + `N` | вернуть последнее уведомление |

## Окна

| Клавиши | Действие |
|---|---|
| `Mod` + `C` | закрыть окно |
| `Mod` + `J` / `K` | фокус по стопке вперёд/назад |
| `Mod` + `Shift` + `Return` | окно в мастер-зону |
| `Mod` + `H` / `L` | ширина мастер-зоны |
| `Mod` + `Shift` + `Space` | плавающее / тайловое |
| `Mod` + ЛКМ | таскать окно |
| `Mod` + ПКМ | менять размер |
| `Mod` + `Shift` + СКМ | сделать плавающим |

## Раскладки и зазоры

| Клавиши | Действие |
|---|---|
| `Mod` + `T` | тайлинг |
| `Mod` + `F` | плавающий режим |
| `Mod` + `M` | монокль |
| `Mod` + `Space` | предыдущая раскладка |
| `Mod` + `-` / `=` | зазор между окнами меньше/больше |
| `Mod` + `Shift` + `=` | зазор в 0 |

Живое значение зазора и толщины рамки хранится в `rice.toml` (`[windows]`) и
едет в vxwm через X resources — пересборка не нужна.

## Теги и холст

| Клавиши | Действие |
|---|---|
| `Mod` + `1`…`9` | перейти на тег |
| `Mod` + `Shift` + `1`…`9` | перенести окно на тег |
| `Mod` + `Ctrl` + `1`…`9` | показать тег поверх текущего |
| `Mod` + `Ctrl` + `Shift` + `1`…`9` | окно сразу на двух тегах |
| `Mod` + `Ctrl` + `H` / `L` / `K` / `J` | двигать холст влево/вправо/вверх/вниз |
| `Mod` + СКМ | тянуть холст мышью (работает и поверх окна) |

Холст — главная особенность vxwm: окна лежат не «на тегах», а на бесконечной
поверхности, а монитор — окошко, через которое ты на неё смотришь.

## Питание

| Клавиши | Действие |
|---|---|
| `Mod` + `Shift` + `L` | заблокировать экран (slock) |
| `Mod` + `Shift` + `F4` | меню: гибернация / блокировка / перезагрузка / выключение |
| `Mod` + `F4` | выйти из vxwm |

Экран блокируется и сам — по простою, если стоит `xss-lock`. Время —
`[power] idle_seconds` в `rice.toml`.

## Мультимедиа

Системные Fn-клавиши: громкость (`wpctl`), яркость (`brightnessctl`),
play/pause и переключение треков (`playerctl`).

## Мышь по бару

| Где | Кнопка | Действие |
|---|---|---|
| тег | ЛКМ | перейти на тег |
| громкость | ЛКМ | окошко с ползунком |
| громкость | СКМ / ПКМ | выключить звук |
| громкость | колесо | ±5 % |
| микрофон | любая кнопка | выключить микрофон; колесо — чувствительность |
| музыка | ЛКМ / СКМ | пауза; колесо — соседний трек |
| часы | ЛКМ | календарь (или своя команда — `[clock] on_click`) |
| прочие модули | ЛКМ | всплывающее окно с подробностями |
