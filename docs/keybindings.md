# Сочетания клавиш

`Mod` — **Alt** (`Mod1Mask` в `vxwm-src/config.def.h`). Хочешь Super — поменяй
там одну строку `#define MODKEY` и пересобери: `./install.sh --existing --no-packages`.

> **Раскладка переключается по Alt+Shift** (`[input]` в `rice.toml`). Поскольку
> `Mod` — это Alt, любое сочетание из колонки `Mod + Shift + …` ниже заодно
> щёлкнет раскладку. Мешает — смени переключатель на `grp:caps_toggle`
> (CapsLock) или `grp:win_space_toggle` (Super+Пробел), либо переведи `Mod`
> на Super.

Всё, что ниже, живёт в `vxwm-src/config.def.h`: это единственный файл, где
описаны хоткеи. При первой сборке из него делается `config.h` — правь его,
твои правки установщик не затирает.

## Запуск

| Клавиши | Действие |
|---|---|
| `Mod` + `Return` | терминал (kitty) |
| `Mod` + `P` / `Super` + `P` | TUI лаунчер приложений (поиск, категории, карточки с ASCII/ANSI артом) |
| `Mod` + `Ctrl` + `P` | ультимативный поиск vxwm-search (=калькулятор, ?веб, ai:ИИ, файлы, :команды) |
| `Mod` + `B` | браузер (firefox) |
| `Mod` + `E` | файловый менеджер (thunar) |
| `Mod` + `A` | локальный ИИ: плавающее окно kitty с `ollama run hermes-8k:latest` |
| `Mod` + `Escape` | выпадающий терминал (прячется тем же хоткеем) |
| `Print` | скриншот (flameshot) |

## Переключатель рабочих столов (Alt+Tab / Super+Tab Switcher HUD)

В стиле Windows Alt+Tab, но специально для **рабочих столов** (воркспейсов) с полноценным оверлеем в реальном времени:

| Клавиши / Действие | Назначение |
|---|---|
| **`Alt` + `Tab`** или **`Super` + `Tab`** | **Открыть оверлей переключения воркспейсов** (HUD по центру экрана) |
| Зажатый `Alt` (или `Super`) + `Tab` | Листать воркспейсы вперед |
| Зажатый `Alt` (или `Super`) + `Shift` + `Tab` / `Ctrl` + `Tab` | Листать воркспейсы назад |
| `Left` / `Right` или `h` / `l` | Навигация стрелками влево / вправо |
| `1` … `9` | Мгновенный выбор конкретного стола |
| **Отпустить `Alt` (или `Super`)** | **Подтвердить выбор и плавно перейти на выбранный стол** (с анимацией tagslide) |
| `Enter` / `Пробел` | Подтвердить выбор |
| `Esc` / `q` | Отменить переключение без смены стола |
| Клик мыши по карточке | Выбрать и мгновенно перейти на этот рабочий стол |

**Особенности дизайна HUD:**
- Темное обсидиановое стекло с мягким скруглением углов (32-bit ARGB) и тенями picom.
- Выделение активного стола светящейся рамкой, акцентной полосой и золотым названием.
- Голубой индикатор-точка на текущем рабочем столе.
- Отображение иконок Nerd Font (` dev`, `󰈹 web`, ` sys`, `󰈙 doc`, `󰚩 ai`, ` media`, `󰒋 7-9`).
- Бейджи запущенных приложений на занятых столах (например, `kitty +2`, `firefox`, `empty`).
- Умный MRU (Most Recently Used): одиночное быстрое нажатие Alt+Tab переключает туда-обратно между двумя последними использованными столами, как в Windows.

## Теги и перемещение окон между рабочими столами

> **Примечание про Shift**: В системе по умолчанию переключение раскладки (US/RU) назначено на `Alt + Shift`. Из-за этого X-сервер перехватывает нажатие Shift при удержании Alt. Чтобы перенос окон работал 100% стабильно и без конфликта с раскладкой, теперь поддерживаются удобные комбинации через **`Ctrl` (БЕЗ Shift)**, а также через клавишу **`Super` (Win)**.

| Клавиши | Действие |
|---|---|
| `Mod` + `Left` / `Right` или `Super` + `Left` / `Right` | **Быстро переключиться на соседний рабочий стол** (БЕЗ Shift) |
| `Mod` + `[` / `]` или `Super` + `[` / `]` | то же самое клавишами `[` и `]` |
| `Mod` + `1`…`9` или `Super` + `1`…`9` | перейти на рабочий стол 1…9 |
| **`Mod` + `Ctrl` + `Left` / `Right`** | **Перенести активное окно на соседний стол и перейти за ним** (БЕЗ Shift!) |
| **`Super` + `Ctrl` + `Left` / `Right`** | то же самое через клавишу Super |
| **`Mod` + `Ctrl` + `1`…`9`** | **Перенести окно на стол 1…9 и перейти за ним** (БЕЗ Shift!) |
| **`Super` + `Ctrl` + `1`…`9`** | то же самое через клавишу Super |
| `Mod` + `Shift` + `Left` / `Right` | перенести окно через Shift (для сетапов с CapsLock/Win+Space для смены языка) |
| `Super` + `Shift` + `Left` / `Right` | то же самое через Super + Shift |
| `Mod` + `Shift` + `1`…`9` | перенести окно на стол 1…9 через Shift |
| `Super` + `Shift` + `1`…`9` | перенести окно на стол 1…9 через Super + Shift |
| `Mod` + `Ctrl` + `Shift` + `Left` / `Right` | отправить окно на соседний стол без перехода |

## Масштабирование и навигация по бесконечному холсту (Canvas)

Холст — главная особенность vxwm: окна лежат не просто на статических слоях, а на бесконечной поверхности, а монитор — подвижная камера над этой плоскостью.

| Клавиши / Мышь | Действие |
|---|---|
| `Mod` + `Ctrl` + `=` (или `+`) | **Приблизить камеру к холсту (Zoom In)** |
| `Mod` + `Ctrl` + `-` | **Отдалить камеру от холста (Zoom Out)** |
| `Mod` + `Ctrl` + `0` | **Сброс масштаба камеры в 100% (1.0x)** |
| `Mod` + `Home` / `Mod` + `Shift` + `Home` | **Вернуть камеру в начало координат холста и сбросить зум** |
| `Mod` + `Ctrl` + `H` / `L` / `K` / `J` | двигать камеру холста влево / вправо / вверх / вниз |
| `Mod` + СКМ (клик колесиком) | панорамировать холст мышью (работает и над окном, и на фоне) |
| `Mod` + Колесико вниз | **Отдаление камеры (Zoom Out)** — работает везде (над окном и на фоне), **только в режиме холста** |
| `Mod` + Колесико вверх | **Приближение камеры (Zoom In)** — работает везде (над окном и на фоне), **только в режиме холста** |

> **Внимание**: В обычном режиме тайлинга зум по `Mod + колесико` отключен и не ломает раскладку окон. Чтобы включить холст и зумить, переключитесь в режим холста (`Mod + F`).

> **Анимации в picom**: При зуме и листании рабочих столов композитор picom плавно догоняет физическое положение окон пружинной моделью (настраивается в `~/.config/vxwm-rice/rice.toml` под `[compositor]`: `animation_stiffness`, `animation_dampening`, `animation_mass`, `animation_clamping`).

## Перезапуск и питание

| Клавиши | Действие |
|---|---|
| `Mod` + `Ctrl` + `R` / `Super` + `Ctrl` + `R` | **Мгновенный перезапуск vxwm на лету** (БЕЗ Shift, без выхода из системы и без закрытия окон) |
| `Mod` + `Shift` + `R` / `Super` + `Shift` + `R` | то же самое через Shift |
| `Mod` + `Shift` + `L` | заблокировать экран (slock) |
| `Mod` + `Shift` + `F4` | меню: гибернация / блокировка / перезагрузка / выключение |
| `Mod` + `F4` | выйти из vxwm в экран входа SDDM |

Экран блокируется и сам — по простою, если стоит `xss-lock`. Время —
`[power] idle_seconds` в `rice.toml`.

## Мультимедиа

Системные Fn-клавиши: громкость (`wpctl`), яркость (`brightnessctl`),
play/pause и переключение треков (`playerctl`).
